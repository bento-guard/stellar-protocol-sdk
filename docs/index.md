# Bento Stellar SDK

Welcome to the Bento Stellar SDK documentation! This SDK is the primary client for AI Agents to interact with the Bento backend and the Stellar Network.

## What is this SDK?

Bento Stellar SDK provides an isomorphic (works in Node.js and Browser), typed, ergonomic interface for agents to execute secure actions (transfers, lending) via the Bento Guard risk engine.
