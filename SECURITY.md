# Security Policy

## Supported Versions

Currently, only the latest major version of the Bento Stellar SDK is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.x | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability in the Bento Stellar SDK, please do NOT report it by creating a public GitHub issue. 

Instead, please send an email to **security@bentoguard.com**.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability that affects the SDK or the Bento Guard Risk Engine, we will work with you to ensure a timely patch is released.
